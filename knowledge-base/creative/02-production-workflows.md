# Creative Production Workflows

Practical workflows distilled from the user's prior creative requests. Adapt each workflow to the current brief.

## A. Reference-based image editing

1. Identify the role of each uploaded image: base image, style reference, replacement object, or exact artwork.
2. Restate internally what must remain unchanged and what must change.
3. Preserve all unmentioned attributes.
4. Make only the requested edit.
5. Check composition, crop, perspective, lighting, edges, and subject consistency.
6. If the user says “do not generate yet”, acknowledge the reference and wait.

## B. Vector cleanup and print preparation

1. Treat the supplied artwork as the unchangeable design reference when preservation is requested.
2. Remove roughness and irregularity without changing the silhouette or geometry.
3. Maintain intentional line hierarchy and uniform stroke behavior.
4. Use clean paths and smooth joins; avoid tiny unwanted nodes and bumps.
5. Keep flat fills clean and colors faithful.
6. Deliver high-resolution raster artwork when requested; clarify if editable SVG/AI/EPS paths are required.
7. For large-format printing, confirm final physical dimensions and output requirements rather than relying on “4K” alone.

## C. Product and packaging mockups

1. Confirm the product form and supplied design artwork.
2. Confirm requested material and dimensions.
3. Apply artwork without changing its content.
4. Match requested views (front, back, hand-held, top, side, or perspective).
5. Keep lighting and scene aesthetic while retaining product legibility.
6. Verify any specified component replacement, such as a transparent lid.
7. Avoid inventing material details when the user explicitly asks for a plain material appearance.

## D. Isolated food/product photography

Use when a user asks for a single food or product asset:
1. Keep only the requested subject and container.
2. Match the requested camera angle (for example, top view).
3. Use the specified aspect ratio.
4. Keep the tabletop/background clean and uncluttered.
5. Match quantity and arrangement precisely.
6. Use a polished stock-photography look when requested.
7. Do not add unrelated ingredients, cutlery, hands, or props unless asked.

## E. Portrait content visual

When the user invokes the established content template:
1. Use 1080 × 1350 px portrait layout.
2. Follow the reference hierarchy and composition.
3. Use photo imagery and/or icon illustrations in a consistent way.
4. Maintain readable title, body copy, and supporting information.
5. Do not change factual meaning while shortening or arranging copy.
6. Keep the visual hierarchy clear and avoid overcrowding.

## F. Character asset extraction

For character assets such as Peppo:
1. Treat the uploaded character reference as authoritative.
2. Preserve pose, gesture, silhouette, accessory placement, and distinctive shapes.
3. If only a character or lettering asset is requested, exclude unrelated background content.
4. For transparent PNG requests, ensure the background is actually transparent rather than white or checkerboard pixels.
5. Match fine details (such as noodle shape, chopsticks, and wing angle) closely to the reference.
6. Do not alter lettering when the user asks for an exact match.

## G. Handoff checklist

- [ ] Correct subject and requested change
- [ ] Reference design preserved where required
- [ ] Correct aspect ratio and dimensions
- [ ] Correct camera angle and crop
- [ ] No unrequested elements
- [ ] Edges and details clean
- [ ] Background/alpha channel correct when transparency is requested
- [ ] Output format appropriate for intended use
- [ ] Any limitations clearly stated
