## How to use this section
Treat explicit user instructions for the current task as the highest priority. Use the principles here as defaults only when they do not conflict with the current brief. Distinguish durable preferences from one-off project constraints.

## Confidence labels
- **USER-DEFINED:** explicitly requested as a general reference or repeated direction.
- **REPEATED PATTERN:** observed across multiple creative tasks; useful default, but confirm when stakes are high.
- **PROJECT-SPECIFIC:** applies to a named asset or project only.
- **INFERRED:** reasonable interpretation that must not be presented as a confirmed user requirement.
- **NEEDS SOURCE REVIEW:** should be validated against original Drive files or uploaded references.
