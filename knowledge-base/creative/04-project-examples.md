# Creative Project Examples & Reference Cases

These are examples from previous user requests. They help explain how the principles apply, but they are not all universal rules.

## 1. Minimalist vector building illustration
**Status:** PROJECT-SPECIFIC

The user supplied a building/house-like outline reference and requested a different building form that retained the minimal outline style without looking identical. A later reference was to be converted into the minimalist style of the first image.

**Lesson:** distinguish style transfer from geometry preservation. When the user permits a new silhouette, retain the line language and minimal visual treatment while changing the form enough to be distinct.

## 2. Strict vector cleanup
**Status:** USER-DEFINED recurring direction

The user requested a strict professional vector conversion prompt to preserve the source design while cleaning uneven outlines for Image Trace and large printing.

**Lesson:** clean contours without redesigning. “4K” is a resolution request, not proof of editable vector output.

## 3. Packaging and merchandise mockups
**Status:** PROJECT-SPECIFIC examples

- Paper bowl: preserve design and color exactly; replace lid with a transparent lid.
- Spunbond tote/goodie bag: preserve uploaded artwork on front and back; show multiple angles and a person carrying it; specified 30 × 40 cm dimensions and no extra material detailing.

**Lesson:** the product rendering may change, but the applied artwork must remain faithful when exact preservation is requested.

## 4. Food/product photography
**Status:** PROJECT-SPECIFIC examples

- Half-boiled eggs: two halves, isolated on a plate, clean tabletop, top-view camera angle, 4:5 ratio, high-quality stock-photo appearance.
- Cocktail sausages: use the same format and arrange a generous amount inside the bowl.

**Lesson:** when the user says “same format”, preserve the prior camera, composition, and output format while changing only the subject or quantity they name.

## 5. Peppo character assets
**Status:** PROJECT-SPECIFIC

The user requested a high-resolution transparent PNG of Peppo holding chopsticks and noodles, matching the reference gesture, noodle shape, wing shape, and wing angle. A separate “peppo is here” lettering asset was requested with no changes.

**Lesson:** small silhouette and shape details matter. For transparent PNG, verify actual alpha transparency. Exact lettering should not be redrawn or modified when exact matching is requested.

## 6. Portrait editorial content template
**Status:** USER-DEFINED reference template

The user explicitly established a portrait 1080 × 1350 template for future visual content, with photo and/or icon illustration examples. One content example covered the ethical concerns around destruction of physical books for AI training.

**Lesson:** apply this template when the user invokes it for subsequent content. Preserve factual nuance and avoid treating the example's subject matter as a permanent brand theme.

## 7. Car/background compositing
**Status:** PROJECT-SPECIFIC

A prior edit requested a daytime Semarang landmark setting, dry pavement, clear bright mood, wider/farther framing, removal of other cars, and a specific gray Agya reference.

**Lesson:** maintain the requested environmental and vehicle details, and use the provided vehicle reference for its appearance and color.
