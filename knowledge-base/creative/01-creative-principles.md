# Ruka Creative Principles

This document captures working principles from explicit creative directions and recurring feedback. It is a guide, not a substitute for the brief or reference assets of an individual task.

## 1. Preserve the supplied reference accurately

**USER-DEFINED / REPEATED PATTERN**

When the user asks to edit, clean up, mock up, or transform an uploaded design while retaining it:
- Preserve the original design, layout, silhouette, proportions, composition, colors, typography, and distinctive details unless a change is explicitly requested.
- Do not redesign, reinterpret, simplify, embellish, or replace elements without permission.
- Change only the specific element or attribute named in the instruction.
- If the user asks for an exact replacement, treat the supplied artwork as the source of truth.
- Ask before generating when the requested transformation is ambiguous and could materially change the design.

Important distinction: some requests explicitly allow a new shape or composition while retaining a style reference. In those cases, preserve the requested style language, not the original geometry.

## 2. Clean, production-ready vector appearance

**USER-DEFINED — repeated vector-preparation requests**

For vector cleanup and tracing preparation:
- Aim for smooth, continuous, controlled contours.
- Keep line weight consistent and preserve intentional outline hierarchy.
- Avoid jagged edges, accidental bumps, rough nodes, wobbly strokes, pixelation, staircase edges, kinks, dents, and abrupt contour changes.
- Use clean, deliberate Bézier-like curves and crisp solid fills.
- Do not add gradients, shadows, textures, or extra details when a flat vector result is requested.
- Preserve the source artwork's geometry and color unless a redesign is requested.
- When asked for 4K or print-ready output, prioritize clean edges and sufficient resolution; do not claim that a raster image is a true editable vector file.

## 3. Mockup fidelity

**REPEATED PATTERN**

For packaging, merchandise, bags, bowls, and other product mockups:
- Apply the supplied design faithfully; do not redraw or alter its artwork.
- Preserve front/back artwork consistency when requested.
- Match the specified material, dimensions, lid, construction, and viewing angles.
- Keep mockup styling and lighting attractive but subordinate to the product design.
- Do not introduce extra logos, text, seams, material details, or decorative elements unless requested.
- If the user asks to replace one object with another reference image, use the second image as the replacement source while retaining the first image's requested scene/composition.

## 4. Visual cleanliness and composition

**REPEATED PATTERN**

Commonly requested qualities include:
- Clean, uncluttered presentation.
- Clear subject separation and intentional framing.
- High-quality, stock-photo-like presentation when a photographic asset is requested.
- Camera angle and aspect ratio should follow the brief exactly.
- Avoid low-resolution or visibly degraded output.
- Do not add unrelated props when the user requests an isolated subject.

These are defaults, not universal constraints. Follow the specific mood, environment, props, and styling in each brief.

## 5. Reference template use

**USER-DEFINED**

A visual content template was explicitly established as a reference:
- Portrait format, 1080 × 1350 px.
- Layout and hierarchy should follow the supplied reference when the user says to use that template.
- Visual examples may use photographic imagery and/or icon illustrations.

Use this template only for content tasks where the user invokes the reference or clearly continues that series. Do not apply it automatically to unrelated assets.

## 6. Exactness and quality control

Before presenting a creative result, check:
1. Did the result change only what the user asked to change?
2. Are the supplied design and reference details preserved?
3. Are aspect ratio, angle, framing, and dimensions correct?
4. Are there unwanted props, text, or background elements?
5. Is the output clean enough for its intended use (screen, mockup, print, or tracing)?
6. Have limitations been stated honestly (e.g. raster output versus editable vector)?

## 7. Current gaps

The following have not yet been established from primary brand documents:
- Ruka's official brand positioning and target audience.
- Official logo, palette, typography, and visual identity rules.
- Standard art direction for all clients or campaigns.
- Formal approval, revision, and handover process.
- Print vendor specifications and color-management standards.

Do not invent these. Extract them from source documents or ask the user when needed.
