# RUKA Knowledge Base

Pusat pengetahuan Ruka untuk dokumentasi, referensi kerja, dan penggunaan AI assistant.

## Prioritas
- **Primary:** CREATIVE — desain, branding, visual identity, packaging, ilustrasi, konten, mockup, produksi cetak, dan produksi kreatif berbantuan AI.
- **Scope:** ALL — seluruh sumber daya workspace yang relevan, termasuk proyek, administrasi, tools, riset, dan arsip.

## Dokumen inti
- [RUKA MASTER KNOWLEDGE](RUKA_MASTER_KNOWLEDGE.md) — indeks dan gambaran sistem.
- [Drive Audit](01-drive-audit.md) — inventaris hasil audit Google Drive yang tersedia.
- [Folder Architecture](02-folder-architecture.md) — struktur 00–09 dan fungsi folder.
- [Resource Register](03-resource-register.md) — daftar sumber daya dan status verifikasinya.
- [Data Governance](04-data-governance.md) — aturan integritas, kepemilikan, dan lisensi.
- [AI Usage Guide](05-ai-usage-guide.md) — cara AI assistant menggunakan knowledge base.

## Status data
Dokumen ini dibangun dari laporan audit yang diberikan pengguna pada 14 November 2026. Audit menyatakan hasil pencarian Drive tidak konsisten dan cakupannya terbatas. Karena itu, semua temuan diberi status sesuai tingkat verifikasi; daftar ini bukan klaim bahwa seluruh Drive telah terinventarisasi.

## Prinsip penting
1. Google Drive adalah sumber asli; repository ini adalah lapisan dokumentasi dan indeks.
2. Jangan memindahkan, menghapus, atau mengubah file sumber tanpa instruksi eksplisit.
3. Jangan menganggap file tidak ada hanya karena pencarian tidak menemukannya.
4. Jangan menyimpulkan isi file dari nama file saja.
5. Tandai informasi yang belum diverifikasi secara eksplisit.
