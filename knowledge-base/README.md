# RUKA Knowledge Base

Pusat dokumentasi dan referensi untuk **Ruka Project Tracking Workspace**.

## Fungsi RUKA
RUKA digunakan untuk mencatat, mengorganisir, dan memantau proyek. RUKA **bukan AI designer**, bukan generator desain, dan bukan sistem untuk membuat keputusan kreatif secara otomatis.

## Cakupan
- **Primary:** project tracking — daftar proyek, klien, task, PIC, deadline, status, progres, prioritas, dan catatan.
- **Scope:** ALL — dokumentasi, referensi, aset pendukung, administrasi, dan arsip yang berkaitan dengan proyek.
