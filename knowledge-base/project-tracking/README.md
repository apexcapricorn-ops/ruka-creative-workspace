# RUKA Project Tracking

RUKA membantu mengelola siklus proyek dari pencatatan hingga penyelesaian.

## Informasi minimum proyek
- Project ID dan nama
- Klien
- Ringkasan pekerjaan
- PIC/owner
- Status dan prioritas
- Tanggal mulai dan deadline
- Daftar task
- Blocker dan next action
- Link folder dan deliverables
- Last updated

## Dokumen
- [Project Record Template](project-record-template.md)
- [Statuses and Workflow](statuses-and-workflow.md)

## Prinsip
Catat fakta yang diberikan. Jangan mengarang field kosong. File kreatif adalah lampiran atau deliverable proyek, bukan tugas desain otomatis untuk AI RUKA.
